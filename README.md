# China Trend Signal

The trend radar for cross-border sellers. We watch Douyin, Xiaohongshu, 1688 and Xingtu so you find the product, the factory price, and the creator rate card — weeks before the trend reaches TikTok.

## Stack
Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · shadcn-style components · 21st.dev orbiting-circles with a canvas particle globe.

## Develop
```bash
npm install
npm run dev
```

## Deploy on Vercel
Import this repo at vercel.com/new — Next.js is auto-detected, no config needed.
